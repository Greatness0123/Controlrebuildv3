**COMPANY** **OVERVIEW**

Control AI is a technology company focused on revolutionizing
human-computer interaction through artificial intelligence. The
company's flagship product, Control, represents a fundamental shift in
how users interact with computers—moving from manual interface
navigation to natural language-driven automation.

Founded by Okorie Greatness in Lagos, Nigeria, Control AI is building
the 'Action Layer' for the desktop—a universal interface that translates
human intent into precise computer actions. The company's mission is to
eliminate the 'Software Mastery Barrier' that prevents billions of users
from fully utilizing the capabilities of modern software.

**Core** **Product:** **Control**

Control is a universal AI agent that operates any desktop application or
system-level setting exactly like a human would. It uses computer vision
to 'see' pixels and graphical interfaces, allowing users to execute
complex multi-app workflows using only natural language voice or text
commands.

**Key** **Differentiators**

> • **Universal** **UI** **Logic**: Instead of relying on brittle APIs
> or plugins, Control parses screen pixels to identify buttons, sliders,
> and menus in real-time. This allows it to drive any software, from
> specialized tools like AutoCAD to general system settings.
>
> • **Hybrid** **Action** **Engine**: Local execution engine for 0ms
> latency in mouse/keyboard actions, paired with high-reasoning Cloud
> APIs for visual understanding.
>
> • **Zero-Knowledge** **Mastery**: Removes the Software Mastery
> barrier. A beginner can perform expert-level tasks in complex software
> simply by describing their intent.
>
> • **Cross-App** **Automation**: Users can chain actions together that
> the OS currently cannot, such as automated file organization across
> multiple applications.
>
> • **Local-First** **Architecture**: Minimizes infrastructure costs and
> maximizes privacy by leveraging user's own compute for interface
> rendering.

**Product** **Components**

Control consists of two integrated components:

> • **Desktop** **Application** **(Electron)**: The primary interface
> for local computer automation. Features voice control with 'Hey
> Control' wake word detection, visual AI for screen understanding, and
> comprehensive mouse/keyboard automation. Supports macOS, Windows, and
> Linux.
>
> • **Web** **Platform** **(Next.js** **+** **FastAPI)**: Cloud
> infrastructure for virtual machine management with remote desktop
> capabilities. Enables users to provision VMs with AI automation
> agents, access them via browser-based VNC streaming, and run
> automation in the cloud.

**HOW** **CONTROL** **FUNCTIONS**

**Technical** **Architecture**

Control's architecture is designed for universal compatibility and
minimal latency:

> • **Visual** **Perception** **Layer**: Captures screenshots with
> cursor position marking. Uses AI to identify UI elements (buttons,
> menus, text fields) through pixel analysis rather than accessibility
> APIs.
>
> • **Reasoning** **Engine**: Processes user intent through large
> language models with visual understanding capabilities. Currently
> supports Google Gemini, Anthropic Claude, OpenAI GPT-4, DeepSeek, and
> local models via Ollama.
>
> • **Execution** **Layer**: Translates AI decisions into precise mouse
> and keyboard actions using @computer-use/nut-js. Implements human-like
> movement curves for applications sensitive to automation.
>
> • **Coordination** **System**: Maps screen positions to a 1000x1000
> normalized coordinate grid for consistent targeting across different
> screen resolutions.
>
> • **Voice** **Pipeline**: Wake word detection via Picovoice Porcupine,
> speech-to-text via Vosk server, text-to-speech via Edge TTS.

**User** **Interaction** **Flow**

The typical user interaction with Control follows this flow:

> • **1.** **Activation**: User says 'Hey Control' or presses a keyboard
> shortcut to activate the assistant.
>
> • **2.** **Input**: User describes their intent in natural language,
> e.g., 'Make this 3D cube look like brushed aluminum and render it.'
>
> • **3.** **Visual** **Analysis**: Control captures the screen and
> identifies the current application context. • **4.** **Planning**: AI
> determines the sequence of actions needed to accomplish the task.
>
> • **5.** **Execution**: Control performs mouse clicks, keyboard
> inputs, and menu navigation to execute the plan.
>
> • **6.** **Verification**: System verifies completion and reports
> results to the user via voice or text.
